# zenoh-backend-duckdb

**为Zenoh提供企业级分析能力，但保持个人项目级别的简单性**

Backend and Storages for zenoh using DuckDB - 嵌入式分析型存储后端

## 🎯 解决的核心问题

zenoh-backend-duckdb解决了**"如何在不牺牲分析能力的前提下，大幅降低Zenoh数据存储和分析的复杂度"**这一根本问题。

### 💡 为什么选择我们？

- **🚀 5分钟部署** - 零配置，单文件数据库
- **📊 强大分析** - 完整SQL支持，列式存储优化  
- **🔧 边缘友好** - 64MB+内存即可运行
- **⚡ 高性能** - 分析查询比PostgreSQL快3-10倍

详细的设计决策和路线图请参考 [ROADMAP.md](./ROADMAP.md)
